# Ako se _web_ aplikacija pokreće lokalno iz _Visual Studio_

Postoji `env.ps1` fajl, koji u sebi sadrži konekcioni string za bazu, naziv i šifra maila koji se koristi iz aplikacije za slanje _newsletters_ i potvrdnog maila da smo kreirali nalog.

Da bi se pokrenula web aplikacija, treba `env.ps1` staviti u folder:

`Grupa1-Tim4\Implementacija\SakuraWeb\`

i iz _Package Manager Console_ pokrenuti ga komandom:

```PowerShell
.\env.ps1
```

Poslije toga se _web_ aplikacija može pokrenuti preko zelenog dugmeta na vrhu ekrana.
